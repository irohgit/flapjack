# Narrative intro

This folder contains the 1920x1080 opening cinematic assembled from the
individual PNG assets in `Assets/Cinematics/NarrativeIntro`.

- Scenes 1-4 show the four narrative subtitle lines.
- Scene 5 introduces the distant pirate fleet without a subtitle.
- Scene 6 waits on the title card until the player presses a key or button.
- Pressing any key/button during Scenes 1-5 skips to the title card.
- Escape always opens `Levels/main_menu.tscn`.

The existing `OpeningCinematic` test scene is intentionally left unchanged.
